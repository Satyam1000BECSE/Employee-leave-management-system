# Employee Leave Management System

A full-stack Employee Leave Management System built using the MERN Stack. This application allows employees to apply for leaves and managers to review, approve, or reject leave requests with role-based authentication and authorization.

---

## 🚀 Features

### 🔐 Authentication & Authorization

- User Registration
- User Login
- JWT Authentication
- Role-Based Access Control (Employee / Manager)
- Protected Routes
- Secure Password Hashing using bcrypt
- Logout Functionality

---

## 👨‍💼 Employee Module

Employees can:

- Login securely
- View Dashboard
- Apply for Leave
- View Leave History
- Edit Pending Leave Requests
- Cancel Pending Leave Requests
- View Leave Status
- Search Leave History
- Filter Leave Records by Type or Status
- View Profile
- View Recent Leave Activities

---

## 👨‍💻 Manager Module

Managers can:

- Login securely
- View Dashboard
- View Pending Leave Requests
- Review Leave Details
- Approve Leave Requests
- Reject Leave Requests with Comments
- Search Employees
- Filter Leave Requests
- View Employee Leave History
- Manage Leave Approvals
- View Recent Activities

---

## 📊 Dashboard Features

### Employee Dashboard

- Total Leave Requests
- Approved Leaves Count
